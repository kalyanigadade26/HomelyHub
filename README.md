# 🏠 HomelyHub

HomelyHub is a full-stack rental property platform that allows users to explore, search, filter, and book properties. Property owners can also list and manage their accommodations through the platform.

## ✨ Features

### 👤 User Features
- User registration and login
- Secure authentication
- User profile management
- Search properties by location
- Filter properties based on:
  - Price
  - Property type
  - Room type
  - Amenities
- View property details
- Book properties
- View booking history
- View booking details

### 🏡 Property Owner Features
- Add new accommodations
- Upload multiple property images
- Add property details and amenities
- Generate property descriptions using AI
- Manage listed accommodations

### 🤖 AI Integration
HomelyHub includes AI-powered functionality to help property owners generate property descriptions from the provided accommodation details.
